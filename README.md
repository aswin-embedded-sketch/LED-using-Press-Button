# LED Control using Push Button with STM32

## Overview

This project demonstrates controlling an LED using a push button with the STM32F446RE microcontroller.

The STM32 reads the status of the push button through a GPIO input pin and controls an LED connected to a GPIO output pin.

This project helps in understanding GPIO input, GPIO output, button press detection, and digital control using STM32.

---

## Components Used

- STM32F446RE Nucleo Board
- LED
- Push Button
- Current Limiting Resistor
- Jumper Wires
- Breadboard

---

## Features

- Reads push button status
- Controls an LED using a push button
- Uses GPIO input and output
- Detects button press
- Demonstrates digital input control
- Uses STM32 HAL library

---

## Software Used

- STM32CubeIDE
- STM32CubeMX
- Proteus Professional
- C Programming Language
